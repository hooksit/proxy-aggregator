# VPN Config Vault (Парсер, Чекер и Панель управления VPN)

Комплексный автоматический сервис для сбора, проверки, отсеивания и экспорта рабочих VPN/Proxy конфигураций по протоколам:
**VLESS, VMess, Shadowsocks, Hysteria 2, Trojan**.

---

## 🚀 Основные возможности

1. **Мультипротокольный сборщик (Parser)**:
   - Автоматический сбор ссылок каждые **12 часов** (интервал меняется в панели).
   - Поддержка источников:
     - Публичные подписки (Base64 или построчный текст).
     - GitHub-репозитории и raw-файлы (по умолчанию подключен `NiREvil/vless`).
     - Telegram-каналы (по ссылке `t.me/s/channel` без необходимости авторизации через Telegram API).
   - Дедупликация конфигураций по уникальному хешу `protocol + server + port + uuid/pass`.

2. **Высокоточный чекер (Health Checker)**:
   - Проверка активного пула каждые **5 минут** (интервал меняется в панели).
   - Единый легковесный движок **`sing-box`**, нативно поддерживающий VLESS Reality, VMess, SS, Hy2 и Trojan.
   - Двухэтапный тест:
     - Мгновенный TCP/TLS пинг порта (отсеивает нерабочие хосты за миллисекунды).
     - Реальное рукопожатие туннеля и замер задержки (RTT Ping) через Cloudflare HTTP 204.
   - Сортировка по минимальному пингу (`ping_ms ASC`).
   - Автоматическое удаление нерабочих конфигураций (если сервер недоступен 3 раза подряд).

3. **Замер скорости до 50 МБ (Speedtest)**:
   - **Кнопка вкл/выкл прямо в панели управления**.
   - При включении замеряет скорость отдачи (Upload) и загрузки (Download) объемом до 50 МБ через Cloudflare CDN, предотвращая излишний расход трафика сервера.

4. **Веб-панель управления (Dashboard)**:
   - **Авторизация**: логин и пароль администратора (настраиваются в файле `.env` или по умолчанию `admin` / `admin`).
   - **Статистика**: время последних и следующих обновлений, число добавленных за 24ч, число живых и удаленных серверов.
   - **Управление расписанием**: изменение интервалов сбора и проверки на лету без перезапуска сервиса.
   - **Ручной ввод**: окно быстрой вставки ссылок или подписок для мгновенного добавления в базу.
   - **Управление источниками**: добавление любых каналов и репозиториев, кнопка принудительного парсинга.
   - **Таблица серверов**: поиск, фильтры по протоколам, цветовая индикация пинга, генератор QR-кодов для мобильных приложений.

5. **Готовые ссылки на подписку**:
   - `/sub/raw` — список ссылок построчно с фильтрами (`?protocol=vless,hy2&limit=50`).
   - `/sub/base64` — стандартная Base64-подписка для V2RayN, Hiddify, Shadowrocket, Streisand, sing-box, Clash.

## 💻 Требования к серверу

| Параметр | Минимальные (до 1 000 конфигов) | Рекомендуемые (до 10 000+ конфигов) |
| :--- | :--- | :--- |
| **ОС** | **Ubuntu 24.04 LTS** (Noble Numbat) | **Ubuntu 24.04 LTS** |
| **CPU** | 1 vCPU (2.0+ GHz) | 2 vCPU |
| **RAM** | 1 GB RAM (+ 1–2 GB Swap) | 2–4 GB RAM |
| **Диск** | 10–15 GB SSD / NVMe | 25 GB NVMe SSD |
| **Сеть** | 100 Mbps | 1 Gbps |
| **Локация** | **Европа** (Нидерланды, Германия, Финляндия) | Без интернет-цензуры |

> [!IMPORTANT]
> Сервер проверки должен быть расположен за пределами зон сетевых блокировок (не в РФ/Китае), чтобы чекер мог беспрепятственно обращаться ко всем узлам.

## 🛠️ Установка на Ubuntu 24.04 в 1 команду

Подключитесь к серверу по SSH и выполните:

```bash
git clone https://github.com/your-username/proxy-aggregator.git /opt/vpn-aggregator && cd /opt/vpn-aggregator && sudo bash install.sh
```

Или скопируйте файлы проекта на сервер и запустите:
```bash
sudo bash install.sh
```

Скрипт автоматически:
1. Обновит системные пакеты.
2. Установит Docker и Docker Compose v2.
3. Скачает официальный бинарник `sing-box`.
4. Запустит сервис в фоновом режиме через Docker Compose.
5. Выведет адрес панели и данные для входа.

После завершения установки откройте в браузере:

- **Логин:** `admin` (или заданный в `.env`)
- **Пароль:** `admin` (или заданный в `.env`, рекомендуется сразу сменить)

## 📱 Ссылки на авто-подписку (Для клиентов)

Вставьте эти ссылки в ваш клиент (V2RayN, Shadowrocket, Hiddify, Streisand):
- **Raw ссылки:** `http://IP_ВАШЕГО_СЕРВЕРА:8080/sub/raw`
- **Base64 подписка:** `http://IP_ВАШЕГО_СЕРВЕРА:8080/sub/base64`

### Параметры фильтрации (Query params):
- `?protocol=vless,hysteria2` — только выбранные протоколы.
- `?max_ping=250` — только серверы с пингом быстрее 250 мс.
- `?sort=speed` — сортировка по скорости (вместо пинга).
- `?limit=50` — ограничение на количество лучших узлов.

## ⚙️ Управление через Docker Compose

- Посмотреть статус и логи:
  ```bash
  docker compose logs -f
  ```
- Перезапустить контейнер:
  ```bash
  docker compose restart
  ```
- Остановить:
  ```bash
  docker compose down
  ```
- База данных SQLite сохраняется в папке `./data` на хосте и не стирается при перезапусках.
